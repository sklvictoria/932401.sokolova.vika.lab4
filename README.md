О проекте:
Веб-страница путешественника с добавлением JavaScript-скрипта для работы с массивами, функциями и условными конструкциями.

Как запустить:
1. Откройте `index.html` в браузере
2. Разрешите выполнение скриптов
3. Введите имя в появившемся окне prompt
4. Откройте консоль браузера (F12 → Console) для просмотра результатов


Ввод/вывод данных
- prompt() — запрос имени пользователя
- alert() — приветствие и вывод результатов маршрута
- console.log() — детальная информация о расстояниях

Функции
- findMaxDistance(arr) — поиск максимального расстояния
- filterLongRoutes(arr) — фильтрация перегонов > 100 км
- calculateTotalDistance(arr) — подсчёт общей длины маршрута (сумма всех расстояний)
